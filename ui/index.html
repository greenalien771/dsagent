Safety

How much the agent is allowed to do without stopping to ask.
Always Allow

The switch the approval card offers, kept in one place. It applies the moment you click it - no Save needed - and stays on until you turn it off here.

Off - every mutating call asks first.
⚠ Dangerous. Ordinary approval prompts are skipped: run_shell and write_file run unattended. Commands flagged as dangerous still stop and ask - this switch can never approve those, and it is ignored in Plan mode.
Dangerous commands always ask

Every shell command is classified before it runs. These categories are never auto-approved, even with Always Allow on, and the approval card only accepts a typed confirmation:

  • Recursive or forced deletes, wildcard deletes
  • Disk, partition, boot and registry operations
  • Privilege escalation, permission rewrites, account changes
  • Piping a download into a shell, obfuscated PowerShell
  • git push --force, reset --hard, clean -xdf
  • Anything touching SSH keys, cloud credentials or the dsagent config folder
Stuck-run protection

Repeating the exact same tool call four times is refused, not retried. A silent run is cancelled by the watchdog, and closing the tab cancels the run instead of leaving it burning steps.
